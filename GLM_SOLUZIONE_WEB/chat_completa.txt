Diagnosi
Dopo il refactoring modulare (commit 3312ad4), la classe FileTreeDrawer è stata estratta da control_center.py in un nuovo file GUI/file_tree_drawer.py, ma l'estrazione è rimasta incompleta: solo 16 metodi su ~50 dell'originale sono stati portati nel nuovo file.

Il costruttore passa metodi come callback a TaskListWidget(...):

python
self.task_list_widget = TaskListWidget(
    on_select_all_toggled=self._toggle_select_all_tasks,   # ❌ mancante
    on_refresh_requested=self._force_refresh_tasks,        # ❌ mancante
    on_delete_checked_requested=self._delete_checked_tasks, # ❌ mancante
    on_clean_queue_requested=self._clean_queue,             # ❌ mancante
    on_task_activated=self._on_task_double_clicked,         # ❌ mancante
    on_context_menu=self._on_task_context_menu,             # ❌ mancante
)
Python risolve self._toggle_select_all_tasks come bound method lookup in __init__ — i metodi mancanti sollevavano AttributeError già in fase di costruzione, bloccando l'intero ControlCenter. Per questo il file manager non appariva.

Inoltre ho trovato altri bug collaterali: QAction e QListWidgetItem usati ma non importati, le funzioni helper _log_user_action / _pause_task / _resume_single_task / _stop_task / _restart_task perse nel refactoring (e control_center.py le chiama ancora).
